# issue-select

My Unit 1 skill. It grades a candidate open-source issue against my rubric and decides whether it's worth taking as a first contribution.

- `rubric.md`: 5 required checks and 2 preferred checks (maintainer activity, repo in use, scope, not claimed, AI policy, failed history)
- `scope.md`: the Path Review repo line and my fit profile, used only to rank accepted issues
- `SKILL.md`, `references/evidence-guide.md`: staff-written

Final eval: 20/20, recorded in `beat-1-sandbox/unit-1/eval-run.txt`.
